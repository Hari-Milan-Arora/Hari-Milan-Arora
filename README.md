## 01. About Me

I am a **Software Engineer and AI/ML-focused Full-Stack Developer** pursuing a B.Tech in Computer Science (Artificial Intelligence), with graduation expected in 2027. I enjoy engineering software that solves practical problems — from designing reliable backend services and responsive user experiences to integrating language models into structured, useful workflows.

My work sits at the intersection of **software engineering, applied AI, and product development**. I focus on maintainable architectures, data-aware systems, robust integrations, and responsible AI features rather than treating an LLM response as a complete product.

- **Software Engineering:** API design, backend architecture, application development, and system integration.
- **AI / ML:** LLM integration, NLP workflows, embeddings, retrieval concepts, and multi-agent orchestration.
- **Full Stack:** Building web applications across frontend, backend, and data layers.
- **Product Mindset:** Translating real user problems into working, testable products with clear constraints.

**Open to:** Software Engineering internships, AI/ML engineering opportunities, backend development, and collaborative product-building projects.

## 04. Featured Projects

<details>
<summary><b>01 · Sentinel Nova — Deliberative AI Chief of Staff</b></summary>

**An AI-assisted planning and productivity system designed to think, verify, and bind before acting.**

Sentinel Nova combines deterministic planning and scheduling with optional Gemini-powered interpretation. Its architecture emphasizes human-confirmed actions, safety checks, and predictable workflow execution.

| Dimension | Implementation |
|:--|:--|
| **Stack** | React, TypeScript, Node.js, Express, Google Gemini API, Vite |
| **Scale** | Multi-agent workflow with specialized planning, prioritization, scheduling, memory, review, and recovery responsibilities |
| **Performance** | Automated test suites, TypeScript checks, and production build workflows; no unsupported throughput claims |
| **Security** | SHA-256 proposal parameter binding, tenant isolation, stale-proposal checks, and human confirmation |
| **Impact** | Structured task planning, prioritization, schedule recommendations, and safer action workflows |
| **Repository** | [Hari-Milan-Arora/Sentinel-Nova](https://github.com/Hari-Milan-Arora/Sentinel-Nova) |

**Engineering highlights**
- Seven-factor task prioritization and multi-strategy schedule deliberation.
- Reviewer gate for constraint validation and cryptographic parameter binding.
- Bounded recovery cycles to avoid uncontrolled retry loops.
- Privacy-scoped memory and explicit human approval before supported actions.
- Automated validation across workflow, isolation, prediction, and LLM-related components.

</details>
